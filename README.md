# iina-sponsorblock-skip

IINA-plugin die hoofdstukken met `[SponsorBlock]` in de titel (zoals yt-dlp ze aanmaakt met `--sponsorblock-mark`) automatisch overslaat.

## Installeren
Of kopieer deze map als `sponsorblock-skip.iinaplugin` naar
`~/Library/Application Support/com.colliderli.iina/plugins/` en herstart IINA.
Pas `SKIP` in `main.js` aan om categorieën te kiezen.

Of: open `sponsorblock-skip.iinaplgz` met IINA (opnieuw bouwen: `zip -j sponsorblock-skip.iinaplgz Info.json main.js`).
